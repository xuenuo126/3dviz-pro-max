# 3dviz-pro-max · 命理可视化

一个纯前端的中国传统命理三维可视化：**紫微十二宫飞星 / 八十年流年螺旋 / 四柱八字** 三视图，支持从幼年到晚年的**逐年演化播放**。

> 传统术数推演，属文化研究与解释，**不构成任何决策依据**。

---

## 三个视图

| 视图 | 内容 |
|---|---|
| **十二宫飞星** | 十二根悬浮晶柱绕周天而列，柱高 ＝ 该宫净数（吉−忌），柱顶小珠 ＝ 所收禄权科忌；弧线为飞星四化，光点沿弧流动 |
| **八十年螺旋** | 2006–2085 共 80 个流年绕成星轨，球体大小 ＝ 影响度（★），颜色 ＝ 吉凶；八大限有垂线标记 |
| **八字** | 上：五行力量；中：四柱（天干 / 地支 / 藏干十神 / 纳音）；下：八步大运；弧线为刑冲合害 |

---

## 逐年演化播放

底部播放条：`▶ 播放` · 进度条拖拽跳年 · 速度 `.25× / .5× / 1× / 2×` · `◎` 相机跟随

每年前进时同步更新：

- HUD 与年卡（干支 · 虚岁 · 流年命宫 · 大限 · 小限 · 流年四化 · 断语）
- 时间轴：当年节点高亮，近五年拖尾
- 十二宫：流年命宫对应立柱提亮 + 光环
- 八字：按年份区间自动切换大运高亮

**快捷键**：`空格` 播放/暂停 · `←/→` 单步 · `Home` 回到起点

---

## 深链参数

| 参数 | 作用 |
|---|---|
| `?year=2028#time` | 直接跳到 2028 年、时间轴视图 |
| `?autoplay=1#time` | 打开即自动播放 |
| `?nobloom=1` | 关闭辉光（低端显卡） |
| `#chart` / `#time` / `#bazi` | 直达对应视图 |

## 技术

- **单文件、零外部依赖**：three.js r160 与后处理链（EffectComposer / UnrealBloomPass / OutputPass 等 10 个 addon）已全部内联，`file://` 双击即可运行
- 约 **1.42 MB**，无构建步骤、无需 Node
- 视觉：UnrealBloom 辉光 · ACES 色调映射 · 程序化环境贴图 · 雷达扫描 · 飞星光流 · HUD 装饰层
- 数据：80 年流年表、十二宫收化、四柱与五行权重，均来自配套命理总集

## 本地运行

直接双击 `index.html` 即可，无需服务器、无需联网。

---

## 部署到 GitHub Pages

仓库根目录即站点根目录，`index.html` 为入口：

1. 推送到 `main`
2. 仓库 **Settings → Pages**
3. **Source** 选 `Deploy from a branch`
4. **Branch** 选 `main`，目录选 `/ (root)`，Save
5. 稍等片刻，访问 `https://<用户名>.github.io/3dviz-pro-max/`
